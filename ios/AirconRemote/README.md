# AirconRemote (iOS)

SwiftUI 製の操作アプリ。操作画面（設定値・今すぐ送る・一発予約を1画面に集約）と設定画面の 2 画面。
アプリを開かずに操作できるよう、App Intents・ウィジェット・コントロールも持つ（ADR-023）。

## 生成と実行

```bash
brew install xcodegen
cd ios/AirconRemote
xcodegen generate
open AirconRemote.xcodeproj
```

`AirconRemote.xcodeproj` は生成物なので gitignore 済み。テストは `AirconRemoteTests`（24 件）。

実機では `AirconRemote` と `AirconWidgets` の両ターゲットで同じ Team を選ぶ。

## 保管場所

| データ | 場所 | 理由 |
|---|---|---|
| APP_TOKEN | Keychain（共有グループ） | UserDefaults や設定ファイルには置かない |
| Worker の URL | Keychain（共有グループ） | 秘密ではないが、ウィジェット拡張から読むため |
| 最後に送った設定 | Keychain（共有グループ） | エアコン状態の正本はアプリ側（ADR-015）。ショートカットからも読み書きする |
| 最後の送信結果 | Keychain（共有グループ） | ウィジェットに1行で出す |

共有グループは `<Team ID>.local.aircon.shared`。App Groups は無料 Apple ID で不安定なので使わない（ADR-023）。旧版で UserDefaults に置いた値は起動時に移す。

## 送信の扱い

- `POST /command` の 202 は「Worker が受け付けて機器へ送った」であり、エアコンが受理した保証ではない（ADR-012）。画面には「送信要求を受け付けました」と出す
- 503 `device_offline` は ESP32 が未接続。設計 §9 の障害判断表を参照
- 予約の `executeAt` は UTC の秒精度 `YYYY-MM-DDTHH:MM:SSZ`。`ExecuteAtFormat` で生成

## アプリを開かずに操作する（ADR-023）

| 場所 | 使い方 |
|---|---|
| ショートカット App | 「おうちリモコン」のアクション（照明、エアコン運転・停止、予約、おやすみタイマー、予約の取消・確認）。オートメーション（帰宅時、時刻、集中モードなど）にも使える |
| Siri | 「おうちリモコンで照明を消灯にして」「おうちリモコンでエアコンをつけて」「おうちリモコンでおやすみタイマー」「おうちリモコンの予約を確認」など |
| Spotlight / アクションボタン | App Shortcuts がそのまま出る。アクションボタンは「ショートカット」か「コントロール」を選ぶ |
| ホーム画面・StandBy | 「照明」「エアコン」「ワンタップ操作」ウィジェット。ボタンはその場で押せる |
| ロック画面 | 「ワンタップ操作」ウィジェット（円形・長方形）、または下部のボタンにコントロールを置く |
| コントロールセンター | 「おうちリモコン」（操作を1つ選ぶボタン）、「おやすみタイマー」（60分後に停止） |
| 背面タップ / Apple Watch | ショートカットを割り当てる（設定 > アクセシビリティ > タッチ > 背面タップ、Watch のショートカット App） |

- エアコンの「運転」で省略した項目は前回送った設定を使う。受け付けられた設定は前回の設定として保存され、アプリの画面にも反映される
- 結果は「送信要求を受け付けました」まで。エアコン・照明が実際に動いたかはわからない（ADR-012）
- ウィジェットとコントロールは iOS 18 以上。アプリを一度起動して設定を共有グループへ移すまでは「未設定」と出る
